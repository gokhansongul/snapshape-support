## About these files

Each page is a single self-contained HTML file with no external resources, and
carries both English and Turkish. The language is chosen from the URL fragment
(`#en`, `#tr`), falling back to the browser's own language; the app links with
the fragment already set. With JavaScript off, both languages stay visible.

The privacy policy describes what the app actually does. If the app changes
what it stores, what it syncs to iCloud, whether its ads are personalised, or
which analytics it sends, this page has to change with it.
